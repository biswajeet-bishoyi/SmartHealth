## ⚠️ Public Health Disclaimer

**SmartHealthNE is a public health surveillance and early warning platform.**  
- Risk scores generated by this system are **epidemiological monitoring indicators** intended for health administrators and frontline field workers.
- **This application is NOT a medical diagnosis tool.**
- Health reports capture reported symptoms and environmental indicators only — **never a definitive disease diagnosis**.

## 🧮 Epidemiological Risk Engine Formula

Computed continuously in `server/services/riskEngine.js`:

$$\text{Risk Score} = (\text{Symptom Score} \times 0.40) + (\text{Growth Score} \times 0.25) + (\text{Water Score} \times 0.20) + (\text{Cluster Score} \times 0.15)$$

All component scores are normalized to **0 – 100**.

| Score Range | Risk Level | Meaning |
|---|---|---|
| **0 – 30** | 🟢 **LOW** | Baseline endemic background |
| **31 – 60** | 🟡 **MEDIUM** | Moderate rise in reported symptoms |
| **61 – 80** | 🟠 **HIGH** | Significant risk — escalates alert to admin queue |
| **81 – 100** | 🔴 **CRITICAL** | Outbreak signal — urgent field deployment needed |

## 🛡️ Role-Based Access Control (RBAC)

- `COMMUNITY_MEMBER`: Submit symptom & water reports, receive emergency alerts, view multilingual preventive guidelines.
- `HEALTH_WORKER`: Access village queue, verify ground veracity of symptom clusters, escalate potential outbreak alerts.
- `NATIONAL_ADMIN`: Access command map, review regional analytics, approve and broadcast emergency warnings.

## 🛠️ Quick Start

### Prerequisites
- Node.js >= 18.0.0
- MongoDB instance running locally on `mongodb://localhost:27017` (or MongoDB Atlas URI)

### Single-Command Setup

```bash
# 1. Clone repository
git clone https://github.com/biswajeet-bishoyi/SmartHealth.git
cd SmartHealth

# 2. Install all dependencies across root, server, and client
npm run install:all

# 3. Seed realistic demo data (3 demo accounts, 65+ health reports)
npm run seed

# 4. Start backend API and frontend client concurrently
npm run dev
```

The apps will launch at:
- **Frontend Web App:** `http://localhost:5173`
- **Backend API:** `http://localhost:5000/api/ping`
